# Question Contracts (`domain/contracts/question/`)

**AI Interview Simulator** — Pydantic schemas representing questions, their evaluations, results, provenance, and runtime metadata.

---

## Package Structure

```
domain/contracts/question/
├── __init__.py                      # empty
├── question.py                      # Question, QuestionType, QuestionDifficulty, SQLTestCase
├── generated_question.py            # GeneratedQuestion
├── question_bank_item.py            # QuestionBankItem
├── question_evaluation.py           # QuestionEvaluation
├── question_result.py               # QuestionResult
├── question_origin_type.py          # QuestionOriginType enum
├── question_provenance.py           # QuestionProvenance
├── question_runtime_lineage.py      # QuestionRuntimeLineage
└── question_runtime_telemetry.py    # QuestionRuntimeTelemetry
```

## Models

### `Question` (`question.py`)

The central question model used throughout the interview lifecycle.

| Field | Type | Default | Description |
|---|---|---|---|
| `id` | `str` | — | Unique identifier |
| `area` | `InterviewArea` | — | Topic area |
| `type` | `QuestionType` | — | WRITTEN, CODING, or DATABASE |
| `prompt` | `str` | — | Question text (min 1 char) |
| `reference_solution` | `Optional[str]` | `None` | Model answer |
| `difficulty` | `QuestionDifficulty` | `MEDIUM` | Difficulty level |
| `humanized` | `bool` | `False` | Whether LLM-humanized |
| `provenance` | `QuestionProvenance \| None` | `None` | Origin metadata |
| `runtime_lineage` | `QuestionRuntimeLineage \| None` | `None` | Selection/assembly trace |
| `visible_tests` | `list[CodingTestCase]` | `[]` | Visible coding test cases |
| `hidden_tests` | `list[CodingTestCase]` | `[]` | Hidden coding test cases |
| `db_schema` | `Optional[str]` | `None` | SQL schema DDL |
| `db_seed_data` | `Optional[str]` | `None` | SQL seed data |
| `expected_rows` | `Optional[list[tuple]]` | `None` | Expected SQL result rows |
| `expected_ordered` | `bool` | `True` | Whether SQL row order matters |
| `runtime_telemetry` | `QuestionRuntimeTelemetry \| None` | `None` | Scoring telemetry |
| `sql_test_cases` | `list[SQLTestCase]` | `[]` | SQL test cases |
| `function_name` | `str` | `"solution"` | Legacy coding function name |
| `coding_spec` | `Optional[CodingSpec]` | `None` | Coding callable spec |

**Helper methods:**
- `is_coding()`, `is_written()`, `is_database()`, `is_execution_based()`

**`SQLTestCase`** (inner model): `id`, `expected_query`, `ordered` (default `True`).

**Constraints:** `frozen=True`, `extra="forbid"`.

### `GeneratedQuestion` (`generated_question.py`)

Used for strict JSON validation of raw LLM output — before it becomes a `Question`.

| Field | Type | Bounds | Description |
|---|---|---|---|
| `text` | `str` | min 10 chars | Question text |
| `difficulty` | `int` | 1–5 | Difficulty rating |

**Constraints:** `frozen=True`.

### `QuestionBankItem` (`question_bank_item.py`)

A question as stored in the persistent question bank (includes full metadata).

| Field | Type | Description |
|---|---|---|
| `id` | `str` | Unique ID |
| `text` | `str` | Question text |
| `interview_type` | `InterviewType` | HR or technical |
| `role` | `Role` | Target role |
| `area` | `InterviewArea` | Topic area |
| `level` | `SeniorityLevel` | Seniority target |
| `difficulty` | `int` | 1–5 scale |
| `ingestion_metadata` | `IngestionMetadata` | Ingestion pipeline metadata |
| `provenance` | `QuestionProvenance \| None` | Origin information |

**Constraints:** `frozen=True`, `extra="forbid"`.

### `QuestionEvaluation` (`question_evaluation.py`)

Result of evaluating a single question.

| Field | Type | Default | Description |
|---|---|---|---|
| `question_id` | `str` | — | Associated question (min 1 char) |
| `score` | `float` | — | Score 0–100 |
| `max_score` | `float` | — | Max possible score (> 0) |
| `feedback` | `str` | — | Textual feedback (min 1 char) |
| `strengths` | `list[str]` | `[]` | Identified strengths |
| `weaknesses` | `list[str]` | `[]` | Identified weaknesses |
| `passed` | `bool` | — | Whether the question was passed |
| `passed_tests` | `Optional[int]` | `None` | Coding: tests passed |
| `total_tests` | `Optional[int]` | `None` | Coding: total tests |
| `execution_status` | `Optional[str]` | `None` | Coding: execution status |
| `tokens_used` | `int` | `0` | LLM tokens consumed |

**Constraints:** `frozen=True`.

### `QuestionResult` (`question_result.py`)

Mutable aggregation of all data for a single question (evaluation, execution, hints).

| Field | Type | Default | Description |
|---|---|---|---|
| `question_id` | `str` | — | Question identifier |
| `question` | `Optional[Question]` | `None` | The question object |
| `evaluation` | `Optional[QuestionEvaluation]` | `None` | LLM evaluation |
| `execution` | `Optional[ExecutionResult]` | `None` | Code execution result |
| `ai_hint` | `Optional[AIHint]` | `None` | AI-generated hint |
| `hint_level` | `Optional[HintLevel]` | `None` | Hint level used |

### `QuestionProvenance` (`question_provenance.py`)

Tracks where a question came from.

| Field | Type | Default | Description |
|---|---|---|---|
| `origin_type` | `QuestionOriginType` | — | Origin category |
| `source_name` | `str \| None` | `None` | Source identifier |
| `source_type` | `str \| None` | `None` | Source kind |
| `dataset_version` | `str \| None` | `None` | Dataset version |
| `retrieval_query` | `str \| None` | `None` | Query used for retrieval |
| `retrieval_score` | `float \| None` | `None` | Retrieval similarity score |
| `generated_by_model` | `str \| None` | `None` | LLM model name |
| `recovery_expansion` | `bool` | `False` | Created during recovery |

**Constraints:** `frozen=True`.

### `QuestionRuntimeLineage` (`question_runtime_lineage.py`)

Runtime trace of how the question was selected and placed.

| Field | Type | Default | Description |
|---|---|---|---|
| `selection_score` | `float \| None` | `None` | Planner selection score |
| `selection_reason` | `str \| None` | `None` | Why it was selected |
| `assembly_reason` | `str \| None` | `None` | How it was assembled into interview |
| `interview_stage` | `InterviewStage \| None` | `None` | WARMUP, CORE, or ADVANCED |
| `planner_rationale` | `list[str]` | `[]` | Planner reasoning log |
| `recovery_applied` | `bool` | `False` | Whether recovery was used |

**Constraints:** `frozen=True`.

### `QuestionRuntimeTelemetry` (`question_runtime_telemetry.py`)

Scoring telemetry for planner ranking.

| Field | Type | Default | Description |
|---|---|---|---|
| `semantic_similarity_score` | `float \| None` | `None` | Semantic similarity to selected set |
| `novelty_bonus` | `float \| None` | `None` | Novelty bonus applied |
| `rarity_bonus` | `float \| None` | `None` | Category rarity bonus |
| `cluster_penalty` | `float \| None` | `None` | Cluster suppression penalty |
| `retrieval_score` | `float \| None` | `None` | Retrieval relevance score |
| `recovered_via_replanning` | `bool` | `False` | Whether replanned |

**Constraints:** `frozen=True`.
